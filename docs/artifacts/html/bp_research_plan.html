1. Why the earlier preliminary results cannot be used

These are the facts as they stand in the earlier notebook and figures. They are listed so the protocol in section 6 can prevent each one.

  • The speckle rotations were appended after the entangling layer, immediately before a Z measurement. rz commutes with Z, and the rx angle had no strength factor, so the strength parameter could not change the measured quantity.
  • The baseline circuit (one Ry layer, a linear CX chain, Z on the last qubit) has gradient variance exactly 2-n. This is a textbook shallow-circuit result, not a finding.
  • Three parameter samples per point. A variance estimate from three samples varies by about 60 times by chance alone.
  • All 64-qubit values (1.7e-5 to 3.1e-4) lie within the shot-noise floor of EstimatorV2 defaults, about 1e-4.
  • No error bars, and no backend, shot count or job IDs recorded. Fig 2 and Fig 4 disagreed by 5 to 8 times on identical points.

3. Literature sweep design

Seven research agents run in parallel, one per bucket. Each produces structured records with these fields: title, arXiv id or DOI, year, venue, main claim, method, largest system size, sample counts and shot budgets, hardware used, relevance to our question, stated limitations, and one quotable sentence.

One synthesis agent then builds the gap map and a ranked list of candidate questions. Before anything is shown to the PI, Claude verifies the top citations by reading the papers directly.

Sources. arXiv quant-ph is primary; nearly all of this literature is open access there. Semantic Scholar and Google Scholar supply citation chains. Publisher sites, via ONOS (One Nation One Subscription) where needed, are used only for the final published versions of a few APS papers.

Credentials. Claude does not need, and should not be given, Owais's ONOS login or any other login. If a specific paywalled PDF is needed, Owais downloads it and uploads it to the thread.

5. Hardware protocol

These rules fix the problems in section 1. They are not negotiable once the allocation clock starts.

  • Nothing runs on the allocation that has not run end to end on the simulator and on the free plan.
  • At least 100 parameter draws per point, 200 for headline points. Bootstrap confidence intervals. Error bars on every figure.
  • The noise floor is measured explicitly on hardware at a point where the ideal gradient is provably zero, and drawn on every plot. Nothing below it is claimed.
  • Minute budget: about 60 percent main sweep, 25 percent independent repeat, 15 percent reserve for a referee's request. Batch mode so queue time is not charged; confirm metering with IBM first.
  • Every CSV row logs backend name, job id, timestamp, shots, resilience level, seed, transpiled depth and two-qubit gate count.
  • Observable indexing checked deliberately. Qiskit Pauli strings are little-endian.
  • API key from an environment variable. Never in source, PDFs or Slack.
