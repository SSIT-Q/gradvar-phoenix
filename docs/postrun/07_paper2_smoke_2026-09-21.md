## 4. What the smoke test decides for the Q1-Q5 campaign, and the Deviations it asks for

   Sampler lists working end to end. The Q1-Q5 lists can be pre-flighted (Deviation 8: days 4-5) once the points below are settled.
2. **Gate P2-2 (i) reading** (coordinator): the literal 90 percent fails by one qubit because the clause, at 2,048 shots, is a 5e-3-resolution

### 4a. Readings adopted (coordinator with the reviewer, 21 Sep 2026, about 10:20 IST; PI countersignature on his next review)

3. **Q2 r = 16: an echo arm is added** (delay 200, X, delay 200 on the spectators, matched in both arms) by Deviation, so the r = 16 contrast is
   recovered rather than the point dropped.
4. **Q4 identity-branch reference: adopt** (H4's t and D bounds read against the delay-branch values measured in the same job, not against zero).
5. **Sampler budget model v3: adopt** (3.0 s per job + (rep_delay + gate + t_meas + 6.5 us) x executions; kill (3) and Gate (iii) re-based on it
